## Теоретичні відомості

- **Вказівник** — змінна, яка містить адресу в пам'яті, де зберігається значення іншої змінної.
- **Динамічний масив** створюється в пам'яті під час виконання програми оператором `new`. Пам'ять виділяється в області heap.
  ```cpp
  int* arr = new int[size];
  ```
- До елементів можна звертатися через індекс `arr[i]` або через арифметику вказівників `*(arr + i)`.
- Пам'ять, виділену через `new`, потрібно звільнити оператором `delete[]`.
- **Динамічний двовимірний масив** створюється через вказівник на вказівник `int**`: спочатку виділяється масив вказівників на рядки, потім пам'ять під кожен рядок. Звільняється в зворотному порядку: спочатку кожен рядок, потім сам масив вказівників.
- **`vector`** — контейнер STL, який представляє динамічний масив зі змінним розміром. Керує пам'яттю автоматично, тому `new` і `delete` викликати не потрібно. Основні методи: `push_back()`, `size()`, `insert()`, `erase()`, `at()`, `front()`, `back()`.

## Завдання 1. «Динамічний одновимірний масив»

**Умова (варіант 1):** знайти найбільший елемент одновимірного масиву.

**Реалізація:** за допомогою вказівника і за допомогою `vector`.

### Код

```cpp
#include <iostream>
#include <vector>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));

    cout << "=== Вказівник ===\n";
    int size;

    cout << "Введіть розмір масиву: ";
    cin >> size;

    int* arr = new int[size];            // виділення пам'яті під масив

    for (int i = 0; i < size; i++) {
        cout << "Введіть елемент " << i << ": ";
        cin >> arr[i];
    }

    int max = *arr;                      // перший елемент - поточний максимум
    int maxIndex = 0;
    for (int i = 1; i < size; i++) {
        if (*(arr + i) > max) {          // доступ до елемента через арифметику вказівників
            max = *(arr + i);
            maxIndex = i;
        }
    }

    cout << "Масив: ";
    for (int i = 0; i < size; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
    cout << "Найбільший елемент: " << max << " (індекс " << maxIndex << ")" << endl;

    delete[] arr;                        // звільнення пам'яті

    // ---------- Частина 2. Реалізація за допомогою vector ----------
    cout << "\n=== Vector ===\n";
    vector<int> vec;

    for (int i = 0; i < 10; i++) {
        int randomNum = rand() % 21 - 10;   // випадкові числа від -10 до 10
        vec.push_back(randomNum);
    }

    cout << "Початковий масив:\n";
    for (int i = 0; i < vec.size(); i++) {
        cout << vec[i] << " ";
    }
    cout << endl;

    int maxVec = vec[0];
    for (int i = 1; i < vec.size(); i++) {
        if (vec[i] > maxVec) {
            maxVec = vec[i];
        }
    }

    cout << "Найбільший елемент: " << maxVec << endl;

    return 0;
}
```

### Пояснення

- **Вказівник.** Розмір масиву і його елементи вводяться з клавіатури. Пам'ять виділяється через `new int[size]`. Максимум шукається обходом масиву через `*(arr + i)`, запам'ятовуються значення і його індекс. Після роботи пам'ять звільняється через `delete[]`.
- **Vector.** Вектор заповнюється 10 випадковими числами від -10 до 10 методом `push_back()`. Максимум шукається звичайним обходом за індексом. Звільняти пам'ять вручну не потрібно.

## Завдання 2. «Динамічний двовимірний масив»

**Умова (варіант 1):** підрахувати середнє арифметичне всіх додатних елементів у даному двовимірному масиві.

**Реалізація:** за допомогою вказівників (`int**`).

### Код

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));

    int rows = 3;
    int cols = 4;

    int** arr = new int*[rows];
    for (int i = 0; i < rows; i++) {
        arr[i] = new int[cols];
        for (int j = 0; j < cols; j++) {
            arr[i][j] = rand() % 21 - 10;   // випадкові числа від -10 до 10
        }
    }

    cout << "Матриця:\n";
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            cout << arr[i][j] << "\t";
        }
        cout << endl;
    }

    int sum = 0;
    int count = 0;
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (arr[i][j] > 0) {
                sum += arr[i][j];
                count++;
            }
        }
    }

    if (count > 0) {
        cout << "Середнє арифметичне додатних елементів: "
             << (double)sum / count << endl;
    } else {
        cout << "Додатних елементів немає." << endl;
    }

    // Звільнення пам'яті
    for (int i = 0; i < rows; i++) {
        delete[] arr[i];
    }
    delete[] arr;

    return 0;
}
```

### Пояснення

Створюється динамічна матриця 3×4: спочатку масив із `rows` вказівників (`int**`), потім для кожного рядка виділяється пам'ять під `cols` елементів. Матриця заповнюється випадковими числами від -10 до 10. Під час обходу сумуються лише додатні елементи, і рахується їх кількість. Середнє арифметичне дорівнює `sum / count`. Якщо додатних елементів немає, виводиться відповідне повідомлення (це захист від ділення на нуль). Пам'ять звільняється спочатку по рядках, потім сам масив вказівників.
